## 📍 台灣口罩地圖 (Leaflet 版)
這是一個基於 Leaflet.js 地圖 API 製作的互動式網頁，串接口罩庫存資料，讓使用者快速查詢各行政區藥局的成人口罩與兒童口罩庫存。

## 📋 專案功能
- 縣市區域聯動：選擇縣市後，自動載入該地區的鄉鎮市區列表。
- 藥局庫存列表：顯示藥局名稱、地址、電話與即時口罩數量。
- 庫存視覺化：
    - 綠色邊框/標籤：庫存足夠（>1000 份）。
    - 紅色邊框/標籤：庫存缺少（<1000 份）。

- 雙向地圖互動：
    - 點擊列表，地圖會自動移動到該藥局並打開氣泡訊息。
    - 點擊地圖標記，可查看詳細資訊。

## 🛠 使用技術
- 介面：HTML5, CSS3, Bootstrap 5。
- 邏輯：jQuery, Axios (非同步資料抓取)。
- 地圖：Leaflet.js (串接 OpenStreetMap 圖資)。

## 📂 檔案結構
- index.html: 主程式頁面。
- js/CityCountyData.json: 台灣行政區劃分資料。
- js/points.json: 藥局庫存與座標資料（健保署資料格式）。

## 🚀 如何執行
下載本專案。
